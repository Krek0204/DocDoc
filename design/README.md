# DocDoc — Design Prototype

Кликабельный React-прототип мобильного приложения DocDoc.

## Запуск

```bash
cd design
npm install
npm run dev
```

Откроется браузер на `http://localhost:5173`.

## Экраны

| Экран | Описание |
|-------|----------|
| Онбординг | 3 слайда: сканирование, реставрация, PDF/Share |
| Главная | CTA «Сканировать», быстрые действия, недавние документы |
| Камера | Viewfinder с рамкой авто-детекции, затвор |
| Галерея | Мультивыбор фото |
| Обработка | Анимация шагов реставрации |
| Редактор | Слайдеры улучшения, обрезка, поворот, мультистраничность |
| Экспорт PDF | Настройки качества, создание PDF |
| Share | iOS-style share sheet |
| Документы | Библиотека с поиском |
| Настройки | Авто-улучшение, хранение |

Навигация: кликайте элементы внутри телефона или выбирайте экран в боковой панели.

## User Flow

```
Онбординг → Главная → Камера / Галерея → Обработка → Редактор → Экспорт PDF → Share
```
