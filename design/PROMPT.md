## Промпт (основной)

```
Спроектируй UI/UX мобильного iOS-приложения «DocDoc» — сканер и реставратор документов.

СУТЬ ПРИЛОЖЕНИЯ:
Пользователь фотографирует документ камерой или выбирает снимок из галереи. Приложение автоматически: обнаруживает границы, выравнивает перспективу, убирает тени, отбеливает фон, повышает читаемость текста. После обработки пользователь может вручную подкрутить яркость/контраст/отбеливание, обрезать и повернуть. Готовый многостраничный документ конвертируется в PDF с настройками качества и сразу отправляется через системный Share (почта, мессенджеры, облако).

ЦЕЛЕВАЯ АУДИТОРИЯ:
Люди 25–55 лет, которым нужно быстро оцифровать паспорт, договор, справку, чек без похода в копицентр.

СТИЛЬ:
- Чистый, профессиональный, доверительный (не игривый)
- Светлая тема по умолчанию, тёмный режим для камеры/редактора
- Акцентный цвет: синий (#1A6FD4)
- Шрифт: SF Pro / Inter
- Минимум декора, максимум ясности
- iOS Human Interface Guidelines, нативные паттерны (tab bar, share sheet, bottom sheet)

ЭКРАНЫ (обязательные):

1. ОНБОРДИНГ (3 слайда)
   - Сканирование документа
   - До/после реставрации (сравнение)
   - PDF + Share
   - Индикатор страниц, кнопки «Пропустить» / «Далее» / «Начать»

2. ГЛАВНАЯ
   - Приветствие + логотип DocDoc
   - Большая кнопка «Сканировать» (камера) — главный CTA
   - Быстрые действия: «Галерея», «Документы»
   - Секция «Недавние» — карточки документов с превью, датой, кол-вом страниц
   - Tab bar: Главная | Документы | Настройки

3. КАМЕРА (полноэкранный тёмный UI)
   - Viewfinder с live-превью
   - Рамка авто-детекции углов документа (4 угла)
   - Анимированная линия сканирования
   - Подсказка «Наведите на документ»
   - Низ: миниатюра галереи | круглая кнопка затвора | переключатель вспышки
   - Верх: закрыть, вспышка

4. ГАЛЕРЕЯ
   - Сетка фото 3 колонки
   - Мультивыбор с чекмарками
   - Хедер: закрыть | «Галерея» | «Готово (N)»

5. ОБРАБОТКА (loading)
   - Превью документа с анимацией
   - Пошаговый прогресс:
     • Обнаружение границ
     • Выравнивание
     • Удаление теней
     • Отбеливание фона
   - Спиннер, галочки на завершённых шагах

6. РЕДАКТОР
   - Тёмный фон, крупное превью документа по центру
   - Бейдж «1 / 3» (мультистраничность)
   - Горизонтальная лента миниатюр страниц + кнопка «+»
   - Нижняя панель с табами: Улучшение | Обрезка | Поворот
   - Таб «Улучшение»: слайдеры Яркость, Контраст, Отбеливание + кнопка «Авто-улучшение»
   - Хедер: назад | «Редактор» | «Далее»

7. ЭКСПОРТ PDF
   - Иконка PDF, название документа, метаданные (страницы, размер)
   - Настройки: Качество (высокое/среднее/низкое), Ориентация, Сжатие
   - Кнопка «Создать PDF»
   - После создания: «PDF готов!» + «Поделиться» + «Сохранить в документы»

8. SHARE SHEET (bottom sheet)
   - Превью файла (имя, размер)
   - Иконки: Почта, Сообщения, iCloud, Копировать, Ещё...
   - Кнопка «Готово»

9. ДОКУМЕНТЫ (библиотека)
   - Поиск
   - Список документов: превью, название, дата, страницы, размер, кнопка share
   - FAB или кнопка «+» для нового скана

10. НАСТРОЙКИ
    - Авто-улучшение после съёмки (toggle)
    - Авто-обрезка границ (toggle)
    - Качество PDF по умолчанию
    - Сохранять оригиналы (toggle)
    - Использовано места
    - Версия приложения

ТРЕБОВАНИЯ К ПРОТОТИПУ:
- Мобильный формат 390×844 (iPhone)
- Кликабельная навигация между экранами
- Реалистичные mock-данные (паспорт, договор, справка)
- Показать user flow: Онбординг → Главная → Камера → Обработка → Редактор → PDF → Share
- Все тексты на русском языке
```

## Ключевые UX-принципы для дизайнера

1. **Один главный CTA** — «Сканировать» всегда на виду
2. **Минимум шагов до PDF** — камера → авто-обработка → share за 3 тапа
3. **Прозрачность обработки** — показывать шаги реставрации, не просто спиннер
4. **До/после** — визуально демонстрировать ценность на онбординге
5. **Нативный Share** — не изобретать свой, использовать системный паттерн iOS
6. **Мультистраничность** — паспорт = 2 страницы, договор = 5+; показать в UI
